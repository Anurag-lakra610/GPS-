# GPS FDK — School of Learning

Interactive website for GPS FDK School of Learning, featuring an exact adaptation of the [Bina School](https://thebinaschool.com/) hero aesthetic and visual rhythm, featuring authentic Indian children on the exploration rock, layered CSS keyframe animations, origami flying bird, dandelion seeds in motion, and editorial storytelling typography.

## Features
- **Hero Section**: Exact visual rhythm and layering of Bina School with rolling meadows, cyan sky, floating dandelion seeds, origami bird, and authentic Indian children on the stone.
- **Interactive Motion**: Fluid keyframe animations (`landingHeroRise`, `landingHeroFade`, `landingHeroIdleFluff`, `landingHeroIdleBird`), interactive hover wiggle CTA.
- **Brand Palette**: GPS Green (`#0D5E3D`), GPS Orange (`#F15A29`), Bina Accent Yellow (`#F7D928`).
- **Responsive**: Fully optimized for desktop (1440px+), tablet (768px), and mobile (390px).

## Tech Stack
- React 19
- Vite
- Tailwind CSS
- Lucide React
